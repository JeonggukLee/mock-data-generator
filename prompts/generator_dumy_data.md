# 依頼概要

## 目的／達成点

DDL（テーブル定義）を入力としてテスト用モックデータを生成・編集・出力できるデスクトップアプリを構築する。

達成点：
- DDLファイルをExplorerから選択・取り込み、カラムの型・サイズ・NOT NULL制約などを解析する
- カラム別に以下の生成ルールを設定できる
  - 連番
  - 定型文の末尾連番
  - フォーマット指定による自動生成（英数字 / 英文字 / 数字 / ひらがな / カタカナ / 記号。フォーマット文字の定義も含む）
  - 値の範囲指定 or 値リストからのランダム選択
- 指定件数分のモックデータを生成し、SpreadSheet形式で画面表示・編集できる
- 出力ボタン押下時、フォルダーとファイル名を指定してDML（INSERT文）をSQLファイルとして保存できる

## 設計意図

モックデータを簡易かつ直感的に作成できることを最優先とし、UI/UXの充実を重視する。
設定入力には各カラムの型・制約に応じたガイダンスを表示し、誤入力を防ぐ設計とする。
技術スタックは現状の Go + Fyne から移行も含めて検討中であり、**まず技術選定の調査・比較を行ってから実装方針を決定する**。

DDLファイルを選択するとカラム情報が自動解析され、カラム別の生成ルールを設定してモックデータを生成するデスクトップアプリ。
